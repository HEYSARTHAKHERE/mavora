# MAVORA Production Launch Checklist

- Configure app URL and canonical domain
- Add production database and connection string
- Configure Supabase Auth and Google OAuth
- Add storage buckets and RLS policies
- Set secure email and notification provider
- Add Stripe or payment provider integration
- Configure queue and background jobs
- Run Prisma migrations and seed scripts
- Validate auth and onboarding flows
- Test core marketing pages and dashboards
- Confirm SEO metadata and social previews
- Perform accessibility and responsiveness QA
- Run production build and smoke tests
